How to read the FAULT line:
  - 'INSIDE buffer' with a plausible offset, TRANSLATION_FAULT -> page-table / mapping bug in the kernel (report the line);
  - 'past the end of buffer' / 'in no buffer' -> userland pointer/size bug (descriptor, tiler heap overflow, like the gfxall5 heap ring);
  - 'in a range UNMAPPED, freed_ago_ms=N' -> use after release (userland freed a BO still used by a later job);
  - random high address, recurring only at 662.5 mV and never after uv_failed=1 (boot rails 750 mV) -> suspect the per-OPP undervolt
    (then boot with n2guv=0 / kern.n2guv=0).
