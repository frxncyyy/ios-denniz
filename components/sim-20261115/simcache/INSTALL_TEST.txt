simcache1 -- userland helper for "Carrier Very 54.0" with no SIM (sim-20261115/simcache). Host-built; NOT run on the phone yet.
Needs kernel q10jfinal16sim2 (0710 kern.n2sim_state + 0713 kern.n2bb_link / kern.n2sim_helper). Built: n2simcache sha256 b4bed8f2...
(build_ios.sh; payloads by make_payloads.py; fake-root rehearsal rehearse-simcache.sh = REHEARSAL_OK, log rehearse-simcache.log).

What it does (one shot per boot, launchd com.nord2.simcache, root, LaunchOnlyOnce): waits for kern.n2sim_state "absent, settled"
(3 reads 2 s apart, up to 300 s); with a SIM -> nothing. If /var/mobile/Library/Carrier Bundles/BundleLinks/{Carrier1Bundle,
Operator1Bundle}.bundle point at a carrier bundle (not Default.bundle) -> removes them, clears com.apple.carrier_1 (com.apple.commcenter,
user _wireless) via CFPreferences, SIGTERMs CommCenter once (launchd relaunches it), waits up to 120 s for kern.n2bb_link = SAHARA done
+ QMUX clients; if the link does not come back it writes the 'norestart' switch (later boots never restart CommCenter again).
Nothing stale -> nothing done (idempotent). Switch files in /private/var/db/nord2-simcache: disabled, norestart, keepkey, dryrun.

Install (phone in fastboot, `phone.py reset fastboot`, lsusb 0e8d:201c):
  cd gpu/build && sim-20261115/simcache/txn_simcache.sh <q10jfinal16sim2 img> TAG              (VARIANT=simcache1)
  safer first run: VARIANT=simcache1-dryrun (logs only)  |  VARIANT=simcache1-norestart (removes links; About clean from the NEXT boot)
  switches later: VARIANT=simcache1-off / -on / -sw-norestart / -sw-keepkey ;  remove: UNDO=1 txn_simcache.sh <img> TAG
Test:
 1. No SIM in the tray, boot. USB log: "NORD2 SIM: +CPIN ... shown to CommCenter 4", then the helper steps
    "NORD2 SIM: helper step 0x5c01...." (start) -> 0x5c02 (no SIM settled) -> 0x5c05000N (N links removed) -> 0x5c060001 (key cleared;
    0x5c06ffff = CFPreferences refused, links still removed) -> 0x5c07xxxx (CommCenter pid killed) -> 0x5c08yyyy (new pid) ->
    0x5c09.... (baseband link back) or 0x5c0a.... (NOT back: norestart written) -> 0x5c0f0003 done. 0x5c04 = already clean.
    Bridge side after the restart: "NORD2 BB: sahara hello/finished" again, "activation register answered".
 2. Settings > General > About: no "Carrier" row (or no Very 54.0); status bar "No SIM"; Settings > Cellular opens.
 3. Reboot (still no SIM): helper step 0x5c04 (already clean), About still clean, no CommCenter restart.
 4. Insert the Very SIM, boot: helper step 0x5c03 (SIM present: nothing); CommCenter matches Very again (About "Very 54.0" back, data,
    SMS, call work) -- the links are recreated by CommCenter itself.
 5. Remove the SIM again, boot: steps as in 1 (removed + restart) -> clean again.
 6. Helper log after a txn snapshot: /private/var/db/nord2-simcache/log (and stderr.log).
Risks: [I] cfprefsd may refuse root writing user _wireless's domain (step 0x5c06ffff; harmless, links removal is the main fix);
[I] CommCenter restart re-boots the virtual baseband (bridge handles power-on/SAHARA at every CommCenter start; with no SIM there is
no service to lose; emergency calls are unavailable for ~20-40 s during the restart); kill switch 'disabled' / 'norestart'.
Undo does not restore removed links (CommCenter recreates them when a SIM is inserted).
