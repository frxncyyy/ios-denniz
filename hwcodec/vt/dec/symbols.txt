# External symbols the DEC06 plug-in objects (vt/dec/n2vtd_nal.c, n2vtd_pixels.c, n2vtd_client_proto.c, n2vtd_obj.c,
# n2vtd_register.c) import on iOS 16, in the format of gpu/video/vt/symbols.txt: image path TAB symbol.
#
# Generated with
#   clang -c --target=arm64-apple-ios16.0 ...   # the five objects
#   llvm-nm --undefined-only ios_n2vtd_*.o
# then mapped to the image whose TBD declares the symbol (the same audit run_tests.sh performs on the linked dylib).
#
# The two n2vcd_transport_* entries come from P03's client library (client/n2vcd_transport.c), which the product dylib
# links statically; they are weak imports in n2vtd_client_proto.c, so a dylib built without P03 still loads and simply
# reports the daemon as unavailable.  The VTVideoDecoder*/VTDecoderSession* and four CoreMedia symbols are declared in
# include/n2vt_dec_abi.h and vt/dec/n2vtd_apple.h because gpu/video's frozen n2_apple.h / n2vt_abi.h do not have them;
# the proposed additions are in vt/dec/STATUS.md.
