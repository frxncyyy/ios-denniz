## Implemented here

`rom_fdt.c` is a freestanding parser for the **original current-boot FDT** passed by LK to `loader.c`. It selects fixed `0x8fb00000..0x8ff4ffff` for iOS only if the target lies within a `/memory/reg` extent, every fixed `/reserved-memory/**/reg` and FDT memreserve entry avoids it, root and reserved-memory address/size cells are two, reserved-memory `ranges` is empty, and the dynamic CONN node is still `no-map`, `size=0x450000`, `alignment=0x100000`, `alloc-ranges=[0x50000000,0x90000000)`. It rejects nested reserved buses and duplicate defining nodes/properties. Existing CONN fixed `reg` or LK `emi-addr`/`emi-size` is a separate inherited-claim route; the fixed-owner parser rejects those to prevent double claims. `rom_contract.c` also validates an inherited fixed CONN `reg`/`no-map` or LK tag when explicitly supplied from those current-boot FDT paths. The output is a **claim**, not a DRAM ownership/permission certificate. It never edits the original FDT, preserving stock chain-back behavior.
