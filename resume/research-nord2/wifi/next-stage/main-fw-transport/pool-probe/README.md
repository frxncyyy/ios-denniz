# Private post-ROM WFDMA preflight and DMA pool probe

This candidate is for one opt-in image only: `nord2wifirom=1 nord2wifidma=1`. It must run after the existing `nrpa_after_persistent()` has returned at stage 16 with ROM_DONE `0x1d1e` and a balanced sleeping AP/WF lifetime. Include `pool_bind.inc` after the canonical ROM binding and call `nppa_after_rom()` immediately after `nrpa_after_persistent()`. The native owner pins the same actual `nrpa_native.rom` placement receipt, persistent phase-10 common owner, accepted ROM result and a distinct `/chosen/nord2-wifi-dma-claim`; it does not call or revive any old ROM/AP wake callback. The selected source preflight implementation remains read-only.

The loader/ADT copies under `../pool-loader-candidate` are private working files, not active sources. Their exact `nord2wifidma=1` gate requires the ROM gate, validates the **current** original FDT and known occupied intervals, and fills a unique 24-byte little-endian `nord2-wifi-dma-claim` only after successful validation. Both `wifi_rom_fdt.c` and `dma_pool_fdt.c` must be linked into the loader. The loader never writes the pool. The native code decodes the claim and rechecks the current boot's high XNU DRAM window before any new radio wake. The reviewed linked image must retain the low-pool no-writeback-alias property; the FDT alone does not prove unknown firmware masters or monitor permission.

The new owner makes one fresh AP1a0 and WF1a4 wake, bounded ACK/readability checks, and live CPU release, top power, power acknowledgment, protection, local ID and ROM_DONE reads. `nwdp_capture` reads exactly 112 selected WFDMA global/ring words. Its complete nonempty or unstable observation returns status 1 after balanced sleep, with zero region18 SET calls and no pool map or write. A callback/ownership failure retains votes for manual reset. Only complete empty/stable preflight enters source-ordered region18 group1 then group0 SET, accepting only each raw x0=0 while preserving x1..x3. Before each irreversible SMC, the native binding emits a captured-only ARM line. Accepted SET maps the full `0x90000000..0x90f20000` pool once with the reviewed Device-nGnRnE low-RAM mapping path, zeros the first 128 KiB as bounded 32-bit words, barriers, reads back all words, barriers, then releases only the new WF/AP votes. The last MMIO write is AP sleep. Success does **not** start WFDMA, reset rings, submit descriptors, copy main firmware, issue INIT commands, or imply FW-ready/scan.

Expected success is `status=0 stage=12 inherited=0 preflight=1 idle=1 stable=1 reads=112`, `attempted=3 accepted=2 raw_valid=3 mapped=1 zero=1 verified=1 words=32768/32768`, and balanced/asleep votes. Complete inherited refusal is `status=1 stage=12 inherited=1`, accepted/attempted/mapped/zero/verified all zero, and balanced/asleep votes. The final captured-only CFG and 27 RING lines allow offline proof of the preflight status. Partial SET, uncertain SMC, map failure, or any zero/readback failure keeps resources and requires manual reset; SET is not replayed or rolled back.
