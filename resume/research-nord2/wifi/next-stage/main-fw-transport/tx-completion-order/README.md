# Private TX completion order correction

Hardware ebfa71f6 copied and verified both patch spans, then failed at CID40 completion before receiving an event. The preserved log records transporterror16, submit1, polls1, noRXbytes, DMA1 HOST_INT_STA0x08000000. Exact selected CODA `soc3_0/wf_wfdma_host_dma1.h:2085,2116–2120` defines bit27 as TX Queue17 completion. Coherent bits20/21 are clear. Error16 is the software pointer/SDL0/DW2/DW3 echo test, not the coherent guard (error24). Current code reaches it only after DIDX advances to the expected next index and a16-byte descriptor sync/read succeeds. The log does not contain those descriptor words or DDONE, so the mismatching field and underlying cause remain unknown.

Selected source `hal_pdma.c:2330–2354` reads DIDX, selects the old software slot, tests `DMADONE`, and stops before consuming any descriptor fields when it is zero. It then uses software Cell.PacketPa and passes descriptor SDLen0 to optional unmap. Source does not perform our immutable pointer/DW2/DW3 echo assertions, but also does not positively establish arbitrary SDL0 mutation as normal. This candidate therefore **retains every existing strict echo check**, moving them only after DDONE1. A partial writeback could explain the old refusal before that source completion fence; this is an unproven hypothesis, not a hardware root-cause claim.

The algorithm still requires expected DIDX plus DDONE1, bounded1000 polls, the same owned slot/buffer and source masks. Pointer/SDL0/DW2/DW3 mismatches after DDONE1 still error16 and halt. Wrong DIDX still errors15; coherent bits20/21 still error24. No extra memory/MMIO reads, prepublication readback, reset, W1C, retry, command replay, relaxed pointer/length contract or erroneous RX rearm is introduced. Strict source command framing and initialized ring layout remain unchanged. A separate prepublication descriptor readback may be useful later, but is outside this narrow order-only candidate.

Append-only `nwt_state` fields capture the intended constructed descriptor (not a claim it was read back), its owned PA, command length, observed DIDX, latest successfully copied raw4-word descriptor, validity and deferred-DDONE count. Valid bit0 means constructed intended words; bit1 means observed words successfully copied after DIDX advance. The mismatch mask is evaluated only after DDONE1: bit0 pointer, bit1 SDL0, bit2 DW2, bit3 DW3. DDONE0 observations are retained and counted while waiting; a timeout leaves their raw words visible with mismatch0 because no completed echo test occurred. No command/calibration payload bytes are logged.
