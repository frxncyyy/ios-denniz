# Actual boot-cache native export, private and default off

This package implements one concrete missing connection: the actual retained normal radio worker can publish a kernel-only immutable copy of its real `ncb_native.rx.scan`. It is an observation of the boot scan, not a newly requested UI scan, a readiness flag, a network interface, a wifid event or an association. Nothing is registered or enabled in canonical code. Existing reviewed lifecycle and conversion packages remain unchanged.

## Exact implemented native hook

`integration.patch` changes only the current `wifi_normal_backend_bind.inc`: include `wifi_scan_export_bind.inc` after the actual ncb_native declaration, and invoke nse_after_normal(result) after ncb_report(result), before returning to the existing parked CAP worker. `proposed/wifi_scan_export_bind.inc` is implemented against the actual retained object names and canonical types. It requires new private opt-in `nord2wifiscanexport=1`; missing opt-in performs no clock read or cache publication. This argument is not added to any current image.

Admission checks the actual worker thread, active/not-parked CAP lifetime and no prior CAP/BASIC/main/init/transport/firmware halt; exact current nct session references to actual basic/cap/init/firmware; original plan/build function/context; phase DONE with all26 commands completed and cursor exhausted; zero reserved credits and balanced acquired/released counts; each actual command publication, TX completion, credit-release, CID/byte-count and sequence correlated with the source plan; real RX session/init identities, idle/nonhalted RX; and an externally requested, inactive bounded nsb scan. A complete scan must have the actual matching state7 completion. Incomplete scans require explicit partial state. No owner callback or off-domain MMIO runs after the native command lease closes.

The existing ncd_native_now reads the same monotonic microsecond clock already used by nsb. Capture must not precede scan.last. Only after admission does a one-shot CAS reserve publication, copy the actual nsb object into static retained RAM, record capture time and release-publish it. Readers acquire publication before receiving a const kernel view. State1 is unavailable, never a partially filled view. No further writer or teardown exists; static storage lasts until reboot. The original radio scan may change later without altering the published copy. Generation1 identifies this sole boot observation only; it is not a client mapping epoch, a firmware ACK, a scan sequence or a later request generation.

`nord2_wifi_scan_boot_view` returns unavailable atomically until publication. It must be called with a kernel-owned output, never a raw externalMethod user pointer. It returns the static immutable source and real capture time for reviewed `nils_prepare`/age conversion. No SSID/BSSID/board/calibration bytes are logged. It can faithfully expose incomplete metadata or a genuinely complete empty scan without inventing networks. It grants no permission to issue radio commands. Populated Apple rows still require the separately unresolved production Apple rate map.

## Concrete next service connection and hard boundaries

The existing private `native-lifecycle-shell-v2/LifecycleShell.cpp` contains the real native method to extend: `NiwlLifecycleClient::dispatchLocked`, selector0/6 after bounded niw_decode and actual owner/task/entitlement admission. The proved request11 GET can eventually use a client-owned reviewed lifecycle-scan-adapter/v2 cursor, and request10 SET must enqueue an actual new request before returning the selected asynchronous semantics. Do not alias request390 BEACON_SCAN_CACHE_REQ to11. GET43 remains the dedicated driver identity; selectors1/5 advertise installed handlers only. `newUserClient` already validates and retains the actual task; close/death already serializes through the native gate. None currently installs this export or a scan callback.

For the boot observation, a future native client may acquire this immutable view, retain its own zeroed output, begin a client ticket under its gate, prepare outside the gate using explicit same-clock reference time, then finish under the gate. Existing nils pointer/serial/generation guards prevent a closed or obsolete callback installing output. The export's boot generation must be associated with the actual client scan/cache session, not substituted for the client's mapping epoch. Inflight client/work/output references must survive close until matching completion; selector4/clientClose may detach a cache but cannot free an output still being prepared. The export itself never owns/free client resources and creates no hidden callbacks.

**A boot cache cannot fulfill live UI scans.** Current canonical `wifi_capability_bind.inc:ncd_worker` parks forever after `nbc_after_cap`. `wifi_normal_transport_bind.inc:nct_native_run` is one-use CAS; `wifi_normal_transport.c:nct_prepare/nct_run` and ncr scan state are also one-use. A real SET10 queue must replace the worker's indefinite park with serialized dequeue, retain each entitled client/generation, establish a new explicit same-native-session lease from the actual completed counter31/next sequence32, reset only fresh software command/scan state under verified owner, and issue a source-derived CID3 using already authoritative regulatory/address/config state. It must not re-run old26 frames, fabricate completed>=5 admission, reenter attempted nct_native, or let an IOUserClient task operate MMIO. Close can cancel queued requests; an already published radio command must finish under its existing bounded owner/deadline, with stale client delivery discarded, rather than fake abort/reset/replay. This transport continuation is not implemented here.

On real completion the per-client cache must be installed before the scan-complete event. The exact same-IPSW event consumer and private event-pipe contracts prove event10/result pull, but no reviewed native producer/notification/cancel implementation is installed. The producer must serialize writes into the real retained descriptors, reserve the full bounded record atomically, publish bytes before release index, send only through the retained current-generation async reference, and drain actual inflight publishers before selector4 frees anything. Queue-full or Mach-send errors cannot become a fictitious completed empty cache. No event is manufactured by this export.
