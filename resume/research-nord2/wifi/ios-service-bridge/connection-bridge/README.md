# Private WPA2 iOS join bridge

This proposal connects the existing IOUserClient transport to a real native station service. It does not implement the radio service, install keys, authorize an image, or establish hardware association/IP. All six production files are in `proposed/shim/nord2-xnu`; canonical files remain unchanged by this package.

`wifi_ios_join.c/h` admits the selected framework's exact592-byte SET20 PMK profile: infrastructure2, open-system authentication1, WPA2-PSK8, PMK cipher6/32bytes, station RSN22 CCMP/PSK without PMF. A zero target selects an actual matching SSID; a nonzero unicast BSSID constrains selection. FORCE_BSSID requires that target. Other active feature, cached-PMK/passphrase, scoped/private identity, association-reason, transition-disable and band-preference options refuse. Padding and proven inactive storage are ignored, not swept for zero. Numeric diagnostics contain no credentials or AP identity.

The selected producer's ordinary passphrase path derives PMK32 and retains native flag4; its ready64-hex PMK path explicitly clears504. This port admits flags0/4 only inside the exact checked WPA2/CCMP PMK profile and implements the negotiation in its own host WPA engine. This is an explicit equivalent port policy, not a recovered proprietary offload implementation. Bit30/cipher10 remain unsupported; CARD75 is not advertised. Original frozen association packages remain unchanged. The immutable followup supersedes their older unresolved event9/ready-PMK statements; this proposal additionally supersedes their flags4 policy. Complete framework CFDictionary execution and the next actual Settings SET20 profile remain unobserved.

`niwj_select` receives native owner-thread immutable actual scan and current channel allowlist. It requires a genuinely completed state7 scan structure, matched sequence, complete IEs, exact SSID/optional BSSID, allowed on-channel observation and measured RCPI. No hard cache-age cutoff is invented; the record retains its observation time and later native authentication/M3 must establish the live peer. The native binder may test several separately completed scans (boot/full and recent UI subsets), but must not invent a merged completion. Selection preserves the original record, full AP RSN and legacy rate BASIC bits. Required unsupported membership/rate selectors refuse. AP RSN must offer CCMP group/pairwise and PSK, cannot require PMF or extended-key-id/NoPairwise; optional SAE/MFPC offers do not become client SAE/PMF support. Group-management trailer must retain the standard OUI. Native station/BSS/WTBL allocations and association receipts remain independently required.

`wifi_station_service.h` is the agreed kernel-only service boundary. Native enqueue copies the secret immediately, serializes on the actual retained worker/scan arbiter and never calls completion inline. Notices run outside its queue lock. IOUC retains its cookie through exactly-once RETIRED, including cancel/close and stale delivery. RETIRED is cookie retirement, not DMA/firmware retirement. Preauthorization cancel closes the port and initiates bounded cleanup; authorized client close detaches delivery without automatically destroying the global connection. Explicit SET22 disconnect closes the real controlled port/carrier synchronously before LEFT. A native snapshot is committed before notice and must derive `associated/ptk_ready/gtk_ready/data_ready` from real owner receipts. Native calls the root-owned ifnet link-down API before iOS revocation notification.

`wifi_ios_station_view.c/h` formats GET21 raw0/1/2/9/21, GET13 state0/1/2/3/4, and current SSID/BSSID/channel/auth/RSSI/1164-byte BSS. Success1/RUN/current association require nonzero native generation/ticket, AUTHORIZED phase, association, PTK, GTK and data-path readiness. GET103 never aliases an unassociated scan cache; ENXIO6 remains its no-association result. Its observed RSSI/IEs retain their original age, with no noise/SNR invention or age reset. Native may update actual current observations later. GET21 backend-unavailable returns NotReady instead of manufacturing pending. GET15 remains infrastructure1 through the existing helper.

The private `wifi_ios_client.cpp` validates the actual owner task, envelope, exact592 bytes/value0/output0 and armed pipe before SET20, wipes heap secret staging and every copied OOL carrier on all paths, and calls native enqueue. It supports base SET22/value0/payload0 only. It publishes terminal event9 only after the current epoch/ticket's snapshot is committed. Event9 is prioritized before optional identity/link notifications if pipe space is scarce; event loss never changes real native authorization. Link4 has the exact32-byte primary and zero SNR/noise when unknown. LEFT publication requires all readiness flags cleared; native must already have closed the port. Client close, pipe disposal and callback races preserve the retained cookie and suppress stale events. As in the existing scan pipe, a full ring may drop a notification; global GET snapshots still reflect real native state.

The selected original consumer proves event4's minimum32bytes at0x1d3eda824, down@0/RSSI@4/involuntary@16/reason@20/subreason@24. The original event9 callback zeroes4116bytes of scratch before primary copy, so a zero-primary48-byte event9 uses safe zero metadata and GET21 fallback; no fictitious152-byte payload is emitted. `source-evidence.json` pins original cache/excerpts and immutable earlier proof. `evidence.py` verifies384 additional producer/consumer instructions against original same-IPSW bytes. The reverse-engineer-anything workflow was read earlier; no connected REA provider was available. This uses ordinary existing-cache checks, no new engine install or target execution.
