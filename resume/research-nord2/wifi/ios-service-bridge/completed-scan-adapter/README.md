Pure adapter from immutable actual nsb_scan to the reviewed1164-byte Apple scan-result cache contract. No hook, registration, task authority, radio operation, network or association is supplied. The actual owner must serialize and retain scan input and the output object, bind a real nonzero scan generation and never copy/relocate the output after cursor pointers are established. This is deliberately stricter than a generic partial-result API.

Only done/state7, matching scan payload sequence, no timeout/partial/dropped and complete bounded records becomes READY. A genuinely completed zero-record scan becomes READY with real EOF immediately. Pending, timeout and partial are distinguished explicitly and never become an empty-success cache or expose cursor EOF. Counts/completion state/channels remain captured metadata. Every populated record is prevalidated before output mutation. Inputs must remain immutable across both validation/encoding passes.

BSS metadata reuses the existing pure source-derived backend decoder: actual BSSID/SSID/IEs/capabilities/beacon interval and valid group3V2 RCPI RSSI. It rejects mismatched channels, truncated IEs, unsupported subtype, missing RSSI and unknown rate conversion. Band flags alone are emitted:2GHz0x8 or5GHz0x10; width/DFS remain unspecified rather than invented from primary channel. Same-IPSW raw-result+12→CHANNEL_FLAGS→CWFChannel.flags identity and named bit consumers are documented in ../channel-mode-audit/selector-resolution/mapping-evidence.json. No scan-request flag semantics are inferred.

Remaining actual-native contracts: verified Apple age-unit values per record and a proven exact IE500kbps→Apple rate table must be supplied. The adapter does not default5.5Mbps to5 or create timing values. Synthetic tests use explicitly synthetic maps/ages only. Native cancellation and owning-task mapping lifetimes remain separate. The empty hardware result can be represented truthfully without those unavailable per-record conversions; actual BSS records cannot be encoded until those inputs are proven.

Tests use actual canonical wifi_scan_bss.h plus frozen existing codec/cursor/mapping/metadata helpers. Clang ASan/UBSan failfast passes completedempty, one populatedrow, metadata/refusal atomicity, bounded ownership/cursor iteration, generation/reentry, partial/timeout/pending. No compile/runtime authority inferred from host tests.
