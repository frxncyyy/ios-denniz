Private captured receipt parser for the shared EID7 source consumer and existing RX/RF snapshot emitter. Portable runtime files are parse-backend.py plus core-async.py; the wrapper checks the exact core digest. It explicitly versions the prior v3 core rather than normalizing new records into invented old ones. Original v3 and RX/RF v1/v2 files remain frozen.

CAP recognized asynchronous events may be bounded ASCII EID27 or EID7 kind3/min40B. CAP SLEEPY n/state pairs exactly between its event and36B header; state is any uint8 and agrees with captured debug_type metadata, not an ACK. CAP debug count remains ASCII only. Final EIDec/actualreply readiness and echo accounting remain unchanged. BASIC ASYNC is mandatory after summary: events=ASCII+sleepy=rearmed<=16, state_valid=bool(sleepy), laststate uint8. Last BASIC DEBUG may describe kind2 ASCII or kind3 EID7; index uses total consumed asynchronous frames. The36B header is still bounded/raw correlated; state byte36 is a separately captured scalar, not header replayproof. No inner/sequence/declared-length equality is imposed for EID7. No ownership handoff, firmwareaction or ACK is inferred.

Normal RXEVENT kind3 already accepted any uint8 status before this revision. That source rule remains unchanged, with explicit all256state regressions. Unknown events, malformed extents, coherent/SWINT/owner failures and total budgets retain refusal. RX/RF snapshot validation is unchanged from reviewed v2, including terminal done cursor correlation and timeout exception. Core success still requires real22 transfers plus actualmatchingSCAN_DONE; raw RF counters stay separate and without invented timeunits; network/interface/association remain false.

Synthetic tests cover all256state values in allthree consumers, opaqueinner/sequence, header/state pairing, totalbudget accounting and malformed/unknown/overflow refusal. They do not replay or infer the unknown state of the failed hardware40B notification. Final source manifest951320e1 and direct emitters are pinned in source-pins.json; actual native clean receipts independently parsed in actual-fixture-report.json. No canonical/stage/CI/device actions here.

For a fresh hardware stage, copy ONLY parse-backend.py and core-async.py side by side (both exactbytes); wrapper import verifies corehash. Run python3 parse-backend.py LOG. No dependency on old stageparser/files; test scripts remain research-only. Existing v3/RFv2 packages and executed stages are immutable.
