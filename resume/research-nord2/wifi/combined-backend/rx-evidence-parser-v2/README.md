Private captured-evidence extension, not a hardware stage or permission gate. `base-v3.py` is byte-identical to the frozen v3 parser and identity checked at import. New exact-known rows are validated and removed before the old core parse; unknown RX/SCAN tags remain visible to its strict rejection. The old22-command receipt, true SCAN_DONE/state7, descriptor/ownership/report rules remain mandatory. RF counters cannot override a failed core receipt, create BSS results, firmwareACK, service, association or network readiness.

Two RXDMA summaries each followed by four RXDMAQUEUE rows occupy their exact source slot after all five RXQUEUE rows. Completed/valid masks prove captured fields; initialized zeroes are not treated as observations. Baseline is mandatory; done requires final reason2, timeout requires reason3. Only event-limit partial may retain the untouched all-zero final snapshot. Queue q0/2/3/4, exact current layout software addresses, cell index/count and ext-address correlation are checked. Actual returned global/control/extension/descriptor words are bounded32-bit observations and may differ from software expectations: diagnosing those differences is the purpose, so no invented echo contract is imposed.

SCANRF exists only with actual decoded SCAN_DONE. It has exactly channel_count<=64 sequential channel rows with8-bit channel/counts and16-bit idle_raw/scan_time_raw. Summary beacons/split counters are raw32-bit; version/pno/sparse scalars raw8-bit. No relationship between raw RF counters and host BSS count, and no undocumented time unit, is inferred. This version returns raw counters tagged as such; these are scalar metadata and never network identifiers or payload/calibration bytes.

Host tests combine the unchanged v3 MAIN seed with the actual synthetic native emitter fixture. They cover complete/partial/timeouts,64-channel limits, missing/duplicated/truncated/unknown rows, widths, masks, addresses/order and arbitrary diagnostic raw words. These tests do not constitute a hardware receipt. No canonical source, original parser/stage, image, gate, CI or device changes occur here.

Version2 adds one source-derived correlation only: on clean done, final captured queue next equals the matching final RXQUEUE next. Snapshot is immediately followed by nsb_complete and pump return, so no later queue mutation can explain a difference. Timeout does not use this equality, since the source can continue pumping after expiry capture. Raw hardware words remain opaque observations. Version1 frozen package is preserved.
