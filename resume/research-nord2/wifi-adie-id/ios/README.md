It preserves installed UFS root readback checks and one-use exclusive flash log. Parent must review/prepare identity and image first, then request exact future boot-only authorization. No final runner is currently usable. Conditional manual recovery authorization for current3b2e/rescue may be included in this exact test approval and must be recorded by parent; runner performs no automatic recovery. Never boot stock Android over iOS userdata.

Parser retains live phase5/60commands/18SET/2reads, active/root1, handoff/rollback/original0, runtime panic and permanent manual-reset semantics. New ADIE RESULT/RESTORE/CLOCK records are strict, bounded, ordered, duplicate-rejecting and preserve raw capture hash. Common adapter precedes final common report with ADIE evidence. Parser checks ID valid/known/complete consistency, source clock bits1/2 and IRQbit0 before any completed SPI/owned semaphore evidence, polls<=1600, strap restore masks, clean flags and semaphore ownership. ID attempt requires all40 common snapshots and verified mutations. Ambiguous command error-6 cannot claim completion/clean release; common error-10 retains all40 common writes, no common restore/outer continuation and dirty halt required. Prepare failure-12 and clean callback failure-11 are distinguished from success.

The source design verifies all40 common registers before GPIO180/reset and CHIP_ID READ, then reverse restores address/semaphore, reset/strap and common registers. Capture reports aggregate restoration and cannot independently prove individual reverse operation order; source review/tests must establish that order. No successful networking inference follows from a known ID. A clean unknown ID is observation, not combined success. Missing ADIE after otherwise clean common success is incomplete under this opt-in template.
