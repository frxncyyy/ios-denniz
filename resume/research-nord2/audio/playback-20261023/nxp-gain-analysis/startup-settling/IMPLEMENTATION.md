# Startup settling and preserved cause

Implemented in the assigned canonical core/test files, without device, CI or commit actions. Parent owns the diagnostic printing, suite registration and overall build.

The selected Android cold path `sound/soc/codecs/audio/tfa98xx/tfa_dsp.c3212–3269` calls INIT_CF. Its state branch at4307–4322 sets MANSCONF1 before PWDN0 and checks system stability. The later proBus OPERATING branch at4330–4345 sets AMPE1. `tfa98xx.c914–970` wraps that start and reads NOCLK once after tfa_dev_start to remove startup sticky status. The previous port instead began PWDN0 before MANSCONF and immediately rejected a single startup status/clock sample before AMPE. Physical seq15 failed inside that strict amp_enable predicate, before any collector record or gain-scaled PCM; cleanup removed its raw evidence.

The corrected port sets MANSCONF1 then PWDN0 with AMPE still disabled. It requires two consecutive samples with CLKS set and TDMERR clear, separated by bounded1ms delays. Historical NOCLK before output enable is recorded but is not an acceptance predicate there. After AMPE1/readback it performs the source-ordered NOCLK read, then requires two consecutive samples with CLKS set and TDMERR/NOCLK clear. Bad samples reset the healthy streak. Persistent or reasserting status/clock faults reach a bounded failure; an I/O error terminates immediately. Each phase allows at most101 samples and100 one-ms delays. Transfer time is additional and retains the existing controller's own hard bound; this is a port settling guard, not a vendor-specified hardware deadline.

There are no raw status-clear writes, gain/thermal/protection register changes, runtime recovery loops, or changes to runtime fault containment. Queued PCM begins only after startup succeeds. Persistent pre-enable faults never set AMPE; post-enable failures disable both outputs through existing cleanup. Expanded gain/default definitions remain intact and do not influence this zero-ring phase.

`nah_status.amp_start[2]` contains `stage`, cumulative sample `attempts`, `valid`, last `status`/`clocks`, first-bad valid mask/stage/attempt/status/clocks, error and failure register/controller evidence. Valid bit0 means STATUS10 and bit1 means the family clock register. Stage values are CONFIG1, PRE_WAIT2, ENABLE3, POST_CLEAR4, POST_WAIT5, READY6 and OBSERVE7. First-bad evidence may describe a transient even on an eventually successful startup; error0 and READY distinguish that from refusal. Records clear only for a newly validated start, before preparatory clock/GPIO actions. Shutdown never overwrites them. `failure_reg` identifies the TFA register involved; failure_pa/value are the last saved controller operation and must not be described as a memory-mapped TFA register.

The saved observation collector also records late startup I/O/status failures through the same helpers. Its actual-source extraction test includes those helpers. Existing deferred printing and partial masks remain unchanged.

New `test-restart-settle.c` uses the real transport, amplifier, board and AFE code with temporal model responses. It verifies initial MANSCONF/PWDN order; initial CLKS blip and delay; transient TDM; post-AMPE NOCLK; post-enable clock dip; persistent/reasserting NOCLK, TDM and clock loss; immediate post-enable I/O refusal; immutable first/last cause through successful cleanup; no AMPE write on persistent pre-enable faults; no PCM on refused starts; and three clean0c74 restarts. Existing full hardware, I2C guard/endian/restore,100ms stop, fatal containment, I2CR/key and saved-observation tests pass with strict warnings, ASan and UBSan.
